# AeroPulse-KZ
Система всепогодной аэродоставки дефибрилляторов (АНД) для первой помощи при мгновенной остановки сердца.
Всепогодная система экстренной аэродоставки автоматических внешних дефибрилляторов при остановке сердца в климатических условиях Казахстана (-35°C... +40°C).

## 🚀 Основные особенности:
- **Всепогодность:** Термоизоляция EPP/Аэрогель, подогрев АКБ для буранов и морозов.
- **Безопасная спуск-лебёдка:** Бесконтактная выдача АНД с высоты 10–15 метров на кевларовом тросе.
- **Двуязычный интерфейс:** Голосовые инструкции АНД на казахском и русском языках.
- **Скорость:** Время подлёта в радиусе покрытия — до 3–5 минут.

## 🛠 Технический стек и материалы:
- **Корпус:** 3K Карбон + ABS-пластик (защита IP65).
- **Связь:** Pro 4G/5G модем + Reserve 868 MHz.
- **Базовая станция:** Автоматический постамат с климат-контролем (+20°C круглый год).
